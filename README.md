# BIN Checker

A Web app that contains identifying of bins of the bank cards.

## API

Register in api website ![link](bin-ip-checker.p.rapidapi.com). Then put the value (key) to the backend code.

## Usage

Insert card's bin to the input box and then add it, to see information.
